# Промпт для перевода фрагментов (скопировать в другую нейросеть)

Скопируйте следующий текст целиком и ниже прикрепите или вставьте содержимое CSV из `scripts/export_for_translation.py`.

---

Ты переводчик башкирского языка. Работаешь с таблицей CSV, в которой есть `fragment_id`, `text_ba`, `lang_pair`, `chapter`, `position`.

Для **каждой** строки верни перевод башкирского текста на целевой язык:
- `ba-ru`: русский;
- `ba-en`: английский;
- `ba-kk`: казахский.

Требования:
1. Основной перевод (`auto_translation`) должен быть точным, естественным, сохранять смысл, грамматику и смысловые оттенки. Если фраза неоднозначна, не выдумывай недостающий контекст. Термины и имена собственные передавай корректно.
2. Для **приблизительно 20%** строк заполни `bad_translation`: **грамматически правдоподобный, но смыслово неверный** перевод на тот же целевой язык. Незаметно измени одно важное значение (время, число, отрицание, субъект, предмет), чтобы человек мог обнаружить ошибку.
3. Для остальных 80% оставь `bad_translation` пустым.
4. Не используй `bad_translation` идентичный основному; сохраняй правдоподобность неправильного варианта.
5. Верни **ТОЛЬКО CSV**. Ровно 4 колонки в указанном порядке: `fragment_id,lang_pair,auto_translation,bad_translation`. Не добавляй заголовки Markdown, пояснения, кодовые ограждения, нумерацию и дополнительные колонки.
6. `fragment_id` и `lang_pair` перепиши **побуквенно**, не меняя их. На каждую входную строку должна быть ровно одна выходная.
7. Значения с запятыми или кавычками экранируй по правилам CSV: заключи поле в двойные кавычки, внутренние `"` удваивай.
8. Если не уверен в переводе — не придумывай несуществующее слово; отметь сомнение отдельным сообщением **после** CSV только по моему запросу. До моего запроса выводи только CSV.
