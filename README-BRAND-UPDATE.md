# Обновление фирменного стиля «Башҡорт теле»

Заменяем только три элемента сайта: блок «Герои башкирских легенд» удаляем, карточку поддержки иллюстрируем чиби-Акбузатом, знак школы делаем геометрическим (семь лепестков курая + открытая книга). Все задания, SQL и маршруты сайта остаются прежними.

Патч из `bashkir-brand-chibi-logo-patch.zip` уже применён к текущей версии. Исходный PNG сохранён рядом с WebP; сайт использует WebP и SVG без внешних библиотек. Скрипт исправлен: удаление старых стилей сохраняет общие правила `.panel` и `.app-rail-card`.

## Как повторно применить на Windows 11

1. Скопируй папки `web/assets/` и `scripts/` из этого архива **в корень своего актуального репозитория** `bashkir-language-school` с заменой только совпадающих файлов (новые имена ничего старого не перезаписывают).
2. Открой PowerShell в корне репозитория и выполни:

```powershell
python scripts/apply_brand_update.py
```

3. Проверь изменения, затем локально запусти сайт как обычно:

```powershell
git diff -- web/index.html
python -m http.server 8000 --bind 127.0.0.1
```

Сайт без API: http://127.0.0.1:8000/web/ . Основной запуск полного приложения через Docker Compose описан в `README.md`. Для уже запущенного стека обновить только сайт: `docker compose --env-file .env.docker up -d --build app`.

**Повторный запуск безопасен**: блок не удаляется вторично, замены не дублируются. Скрипт создаёт `.index.html.before-brand-update.bak` — копию исходного файла. Этот backup не коммить в Git.

## Что проверять

- Нет секции «Герои башкирских легенд».
- Логотип в левом верхнем углу и favicon — знак книги и курая. Он работает без сторонних библиотек.
- В маленькой боковой карточке вместо прежней картинки — чиби-Акбузат.
- Карта, задания, очки и рейтинги не изменены. TTS по-прежнему не реализована.
- На телефоне нет горизонтального переполнения, белых квадратов вокруг маскота или сломанных ссылок.

Не выкладывай скриншоты с токенами, не запускай `docker compose down -v`.

## Автоматические проверки

`python -m unittest discover -s tests -q` проверяет также повторное применение патча, сохранность backup, учебного JS и общих CSS-правил. `python tests/browser_visual_checks.py` проверяет шесть размеров экрана, реальные локальные изображения, favicon, отсутствие секции легенд и рабочий урок без CDN. Снимки — `test-results/visual/`; в Actions — артефакт `interface-screenshots`. Backup исключён из Git через `.gitignore`.
