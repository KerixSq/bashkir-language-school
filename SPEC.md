# Функциональная спецификация

**Платформа:** веб-страница + Telegram-бот + PostgreSQL с REST API. Языковые пары: `ba-ru`, `ba-en`, `ba-kk`.

- Фрагмент текстового источника содержит `source_id`, `chapter`, `position`, для аудио также `time_start` и `time_end`. Stage13 поддерживает импорт WAV/MP3 с готовой разметкой и воспроизведение безопасного локального диапазона. Статическая башкирская TTS доступна отдельно для 40 фраз колоды. Произношение требует оценки носителем (docs/CONTENT_AND_AUDIO.md).
- Telegram FSM хранит состояние в `users.state`; участники выбирают роль, никнейм и языковую пару. Ученик может заниматься без класса и вступить позже через /join; преподавателю нужна подтверждённая привязка к классу.
- По заданию показывается башкирский текст и автоматический перевод; иногда — заранее подготовленный неверный вариант. Ответ — подтверждение или исправление. Один участник отвечает на одну пару один раз.
- PostgreSQL делает нормализацию, сопоставление по словарю `synonym_map`, вычисляет фиксированные веса голосов, консенсус и очки. Минимум 3 человека, порог веса 0.6; после 5 голосов без консенсуса — `expert_review`.
- Экспертный раздел с отдельным секретом позволяет утвердить итог, `expert_decisions` и `status_history` сохраняют след изменений.
- `translations_export` содержит строго `fragment_id,text_ba,lang_pair,translation,source,confirmed,status`; `confirmed` — число голосов за выбранный вариант.
- Публичные рейтинги пользователей обезличены и используют только никнеймы; школы и классы учитывают только учеников.
- Отчёт преподавателю по длинному `teacher_code`, создание классов — по другому коду приглашения; внешняя интеграция использует отдельные API-ключи и `external_answers`.
- Антинакрутка: интервал 2 секунды, минимум 2 секунды между показом и ответом, 150 очков в день, ограничения веса 0.5–1.5. Согласованный сговор разных аккаунтов всё ещё возможен.
- Веб: один HTML, самостоятельная игра на реальном корпусе с локальными XP, картой, наградами, пятью заданиями в уроке и тремя этапами; также рейтинги, экспорт CSV/JSON, отчёт, очередь эксперта и REST-примеры. Все данные API выводятся безопасно.
- Тестовые материалы создаются отдельно и помечены `license='demo'`; не считаются лингвистически проверенными.
- Публичная модель без семантического ИИ, экспертное решение не является независимой институциональной проверкой.

Развёртывание и параметры: `README.md`. Форматы и права REST: `API.md`. Руководство пользователя: `docs/PRODUCT_GUIDE.md`.

## Корпус разговорников БГПУ

Скрипт `scripts/import_phrasebooks.py` читает пять локальных JSONL-файлов корпуса [Bashkorttele](https://huggingface.co/datasets/bashkorttele/trilingual-parallel-phrasebooks-bgpu), CC BY 4.0. Дедупликация `text_ba` формирует пары `ba-ru` и `ba-kk`. Исходные идентификаторы и координаты строк хранятся в приватной `phrasebook_rows`. Подставные варианты для части пар — другие фразы того же файла, без нейросети. Выравнивание троек корпуса требует ручной проверки. Демо-школы и пользователи создаются без непроверенных текстов по умолчанию.

## Отдельная игра в браузере

`web/index.html` показывает реальные упражнения: выбор перевода, обнаружение ошибки, составление перевода из слов и ввод ответа. Учебные пары берутся из опубликованной локальной колоды `web/assets/learning-deck.json` (создаёт `scripts/export_learning_deck.py` по локальным JSONL БГПУ) либо из публичного `translations_export` со статусом `confirmed`. В репозитории включены 700 реальных фраз корпуса: по 350 для ba-ru и ba-kk. Тренировочные XP, серии и достижения сохраняются только в localStorage. Ответы веб-игры не влияют на консенсус или рейтинг классов Telegram-бота. Перед полноценным запуском требуется проверить качества корпуса.

## Локальная установка

Основной запуск PostgreSQL, Auth, REST и сайта на Windows 11 — Docker Compose по README.md. Supabase CLI остаётся альтернативой по `docs/LOCAL_WINDOWS.md`; внешний облачный проект необязателен. Локальная среда разработки не публикуется в интернет.

## Кооперативная библиотека Акбузата

Публичный SQL-view `adventure_progress` возвращает **только агрегированные** подтверждённые и спорные переводы по языковой паре, без ID пользователей и без демо-источников. Сайт показывает реальные числа и открывает главы при 1, 5 и 15 подтверждённых переводах. Личные очки браузера остаются локальными и не влияют на согласование PostgreSQL.
## Telegram и общая платформа

P1: добровольные ежедневные напоминания через /remind on/off и меню. Существующие reminders_enabled/last_reminder_date используются с серверными часами Уфы, атомарным claim, повторной проверкой цели/согласия/удаления и обработкой блокировки. Изначально выключены; отдельного polling нет, доставка exactly-once не обещается. Документация: docs/TELEGRAM.md.

P1/ТЗ 4.2: CLI импорта WAV/MP3 и готовых CSV/JSON таймкодов, атомарная запись sources/fragments/fragment_pairs, повторяемый импорт и проигрыватель оригинального диапазона. Технический тон в тестах не является башкирской речью. Подробности: docs/CONTENT_AND_AUDIO.md.

P1/ТЗ 4.4: экспертная очередь показывает пары похожих нормализованных ответов, голоса и pg_trgm score. Решение остаётся ручным через expert_resolve; автоматического объединения и добавления в synonym_map нет. Реализация и ограничения: docs/EXPERT_REVIEW.md.

Ученик может зарегистрироваться самостоятельно без class_id и позднее вступить по `/join`, сохранив ответы и баллы. Преподавательская авторизация по коду класса сохранена. Меню и личный вклад используют серверную PostgreSQL, а ссылки на другой канал не объединяют аккаунты. Инструкция: docs/TELEGRAM.md.

Актуальные проверки и ограничения: [QA](docs/QA.md).
