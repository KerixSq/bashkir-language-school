    О проекте

    Каждый день участники проверяют перевод башкирского текста и предлагают исправления. Когда достаточно людей согласны, мы сохраняем вариант в базе.

    Как проверяем качество

    Сравниваем текст по правилам нормализации и словарю вариантов. Это не распознавание смысла: синонимы без записей в словаре можем считать разными. Спорные случаи передаём экспертам.

    Что видно другим

    В публичных рейтингах — никнеймы, без Telegram-имён и личных идентификаторов. Для отчёта класса нужен отдельный секретный код.

    Разговорники содержат переводы, выравнивание которых не проходило построчной проверки. Озвучка и экспертная проверка носителями языка не выполнены автоматически.

    Для разработчиков

    База доступна через Supabase REST. Данные отдаются в JSON, для внутренних операций есть RPC.

    Получить подтверждённые переводы

    Подключи Supabase, чтобы получить пример запроса.

    Как устроены данные

    Источник → фрагмент на башкирском → перевод для пары языков → ответы пользователей → согласованный перевод.

    Публичные: translations_export и рейтинги. По ключу партнёра: api_get_fragments, api_submit_answer. Только серверу: user_stats, ответы и персональные данные. Код преподавателя нужен для отчёта.

    Партнёрский API

    POST /rest/v1/rpc/api_get_fragments
{ "p_key": "bsk_...", "p_lang_pair": "ba-ru", "p_limit": 10 }

    Схема: sources → fragments → fragment_pairs → answers → translations_export. Внешние ответы пишутся отдельно в external_answers и не получают очков.

    Полный список полей, прав и примеров запросов — в API.md репозитория.
