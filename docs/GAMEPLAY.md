# Игровой режим на сайте

## Что это

Самостоятельная короткая игра без регистрации: 5 упражнений за урок, три последовательные зоны, XP, серия дней и достижения. Графика вдохновлена эпосами «Урал-батыр» и «Акбузат». Уровни открываются после 8 и 20 впервые успешно выполненных разных фраз.

Упражнения: выбрать перевод из нескольких, определить ошибку, собрать перевод из слов, написать ответ. Учебный ответ сравнивается по нормализованному тексту. Синонимичные ответы без совпадающих форм по-прежнему могут быть отклонены. Ошибочные фразы будут встречаться повторно в будущих уроках. При удачной попытке игрок получает 15 XP за новую фразу, 5 XP за повтор; за попытку с ошибкой — 2 XP. Эти XP сохраняются **только в localStorage** и не связаны с очками Telegram.

## Данные

Веб-игра читает `web/assets/learning-deck.json`. В архив вложены 6 исходных фраз из открытой карточки корпуса для первого знакомства. Это не выдуманный текст, но и не проверенные экспертами переводы. Для полного прохождения карты выгрузи расширенную колоду: После скачивания пяти оригинальных JSONL-разговорников БГПУ:

```powershell
.\.venv\Scripts\python.exe scripts\export_learning_deck.py --dir .\data\phrasebooks --per-pair 350 --seed 42
python -m http.server 8000
```

Открой http://localhost:8000/web/. Если игра не видит колоду, проверь путь `web/assets/learning-deck.json` и обнови страницу. Можно также выбрать локальный файл JSON через игровую форму. При пустой колоде и наличии публичного подключения Supabase игра использует только `translations_export` со статусом `confirmed`.

**Права:** https://huggingface.co/datasets/bashkorttele/trilingual-parallel-phrasebooks-bgpu (лицензия CC BY 4.0 по текущей карточке; обязательно сверь с `LICENSE` и `NOTICE` скачанной версии перед публикацией). Экспортёр не создаёт новых переводов. Выравнивание исходного корпуса не проверялось построчно; перед пилотом нужен контроль качества.

## Границы функциональности

- Веб-очки, награды и серии хранятся только на устройстве. Серверные очки браузера и Telegram в одной системе рейтингов, а тренировочные XP отделены.
- **Тренировочные** упражнения не отправляют ответы в Supabase и не влияют на консенсус. Для официального голосования теперь есть основной режим «Учись. Проверяй» на сайте; Telegram остаётся альтернативой.
- Задания без реальных фраз не появляются; вымышленный языковой контент не встроен.
- Согласование синонимов по смыслу, аудио и TTS не реализованы.
- Не делай вывод об уровне владения языком только на основе игровых XP.

## Проверка

Пройти урок в браузере; ошибиться и увидеть ответ корпуса; вернуться на следующий урок и встретить повторение; открыть 8/20 разных фраз и увидеть новые зоны; перезагрузить страницу и убедиться, что XP сохранились; открыть приватную вкладку и проверить пустой локальный прогресс.

## Общая библиотека Акбузата (серверные данные)

Вверху игровой карты есть отдельный счётчик подтверждённых переводов. Он **не** связан с `localStorage` и не зависит от игровых XP. Сайт читает публичный view `adventure_progress`, группирующий результаты по `ba-ru`/`ba-kk`. В счётчике только уникальные пары со статусом `confirmed`; демо-источники не учитываются. Глава I открывается после 1 перевода, II после 5, III после 15. После подтверждения фразы участниками в Telegram нужно нажать «Обновить прогресс» на сайте. При отсутствии API показывается сообщение, а не выдуманное число.

Для локального REST API на ноутбуке настрой `http://127.0.0.1:54321` и публичный ключ. С других устройств `localhost` работать не будет (см. `docs/LOCAL_WINDOWS.md`).
