# Academy Edition — что реально проверено

## Исходная задача

Упростить основное обучение и сделать интерфейс сопоставимым по качеству навигации с примером LinguaLearn, не переписывая существующую архитектуру и не копируя чужую графику.

## Изменено

- `web/index.html`: основной экран, визуальная система, маршрут из трёх реально доступных/заблокированных этапов, экран упражнения, поддержка клавиатуры, мобильное представление.
- `web/assets/ural-journey.webp`: оригинальный пейзаж Урала для заглавного экрана.
- `tests/test_academy_ui.py`: пять контрактных тестов.
- `tests/browser_learning_path.py`: необязательная браузерная проверка полного урока (две ширины, настоящая локальная JSON-колода).
- `README.md`, `docs/UX_REFERENCE.md`: инструкции и описание.

Промежуточные SQL-миграции, логика PostgreSQL, Telegram-бот и корпус БГПУ не изменялись.

## Проверено в песочнице

- Python `unittest`: **98 тестов прошли**.
- `compileall`: **успешно**.
- JavaScript: **6 inline-скриптов прошли синтаксический разбор**.
- Браузер Chromium: главная кнопка открывает первый настоящий урок из локального `learning-deck.json`.
- Chromium: пять разных вопросов проходят до экрана итогов, XP накапливаются; на десктопе 1440px и телефоне 390px ошибок JavaScript и горизонтального переполнения нет.
- Заблокированные этапы имеют `disabled` и не разблокируются автоматически при сетевых операциях.
- Встроенные SVG-иконки видны даже без загрузки сторонних шрифтов.

Браузерное тестирование проведено **без подключения к реальному Supabase**: локальная колода была загружена из архива через перехват запроса. Не утверждаем, что проверена PostgreSQL-интеграция.

## Что нужно проверить на компьютере команды

1. Запустить веб-сервер из корня проекта `python -m http.server 8000` и открыть `http://127.0.0.1:8000/web/`.
2. Пройти гостевой урок до экрана итогов на смартфоне и на десктопе; проверить вход, выход, серии и сохранение прогресса после обновления.
3. Настроить локальный Supabase по `START_HERE.md`, затем проверить настоящий браузерный вход и три подтверждения перевода.
4. Запустить `scripts/check_rls.py` и `scripts/smoke_test.py` на живой базе.
5. Проверить атрибуцию и качество перевода выбранных фраз корпуса с носителем языка.

## Известные ограничения

- Веб-игра и коллективная проверка перевода пока имеют разные системы XP (локальные и серверные); смешивать их нельзя.
- Tailwind Play CDN и другие CDN нужны для части дополнительных эффектов; для хакатонного прототипа их можно использовать, базовая верстка и встроенные SVG работают без них.
- Локальная Supabase CLI не является публичным хостингом. На чужом телефоне нельзя обращаться к `127.0.0.1` ноутбука.
- Единственная проверка SQL-прав в репозитории без реальной базы — статическая; настоящий RLS нужно проверять отдельно.
