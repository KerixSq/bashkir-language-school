# Редизайн по мотивам LinguaLearn — что переняли и что сохранили

Референс `lengualearn-main.zip` изучен как пример организации учебного приложения: понятная карта уровней, один учебный вопрос на экран, крупные ответы, немедленная обратная связь, счётчик прогресса и отдельные разделы пользователя.

**В проект не копировали React-код, изображения, логотип или оформление LinguaLearn.** Сохранили собственную архитектуру: один `web/index.html`, SQL-функции PostgreSQL, Telegram-бот aiogram и корпус разговорников БГПУ. Навигация и внешний вид переработаны специально под башкирскую тему, с Акбузатом и пейзажами Южного Урала.

## Главное для ученика

- «Играть бесплатно» запускает первый доступный урок из локальной колоды, не требует базы и не начисляет баллы сообщества.
- Карта показывает три настоящих этапа, другие открываются после 8 и 20 уникальных освоенных фраз; пустых игровых точек нет.
- Урок занимает весь экран: пять заданий, большие варианты, видимый прогресс, ответы с клавиатуры (1–4, Enter) и явная обратная связь.
- Награды и тренировочные XP хранятся на устройстве. Серверные баллы за проверку переводов считаются отдельно.
- Проверка переводов, рейтинг школ/классов, JSON/CSV и спорные случаи сохранены и используют те же RPC/View, что раньше.

## Технические исправления

- Асинхронная браузерная проверка больше не открывает случайно ранее закрытые уровни: перед блокировкой интерфейса запоминается исходное состояние каждой кнопки.
- Вход в проверку переводов ведёт к видимой карточке, даже если блок регистрации скрыт после входа.
- Кнопка на первом экране запускает настоящий урок, а не просто прокручивает страницу.
- На мобильном во время полноэкранного урока нижняя панель навигации не закрывает кнопку подтверждения ответа.
- Основные иконки навигации встроены как собственный SVG-спрайт: они работают без стороннего CDN.

## Проверка

```powershell
python -m unittest discover -s tests -v
python scripts/check_contract.py
python -m http.server 8000
```

Открой `http://127.0.0.1:8000/web/`. Для отдельного браузерного smoke-теста сначала установи Playwright, затем `python -m playwright install chromium` и `python tests/browser_learning_path.py`. Он тестирует гостевой урок без подключения к Supabase. Для подтверждения работы SQL, RLS и Auth нужны отдельные интеграционные тесты с подключением к реальной базе.
