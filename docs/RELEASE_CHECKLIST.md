# Перед защитой и публикацией

Все команды выполняются из корня проекта в PowerShell на Windows 11.

## Проверки без базы

```powershell
.\.venv\Scripts\python.exe -m compileall -q bot scripts tests
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts\check_contract.py
.\.venv\Scripts\python.exe -m pip install ruff
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
```

## Реальная база

1. Создай резервную копию или экспорт таблиц Supabase.
2. Останови прежнего бота и примени только `sql/migrations/20261113_stage5_quality.sql`, если stage1–stage4 уже выполнены.
3. Запусти `scripts/check_rls.py`. Сетевая ошибка не является PASS.
4. Запусти `scripts/demo_readiness.py`, проверь предупреждения о пустом корпусе.
5. Запусти `scripts/smoke_test.py --expert-code "КОД"` с секретом, полученным из `setup_access.py`.
6. Проверь, что повторное применение миграции не создаёт дублей и не теряет ответы.

## Данные

1. Проверь `LICENSE` и `NOTICE` датасета, заполни правообладателя в README.
2. Выполни импортёр с `--dry-run --review-out .\data\review.csv`.
3. Проверь с носителем языка отобранные фразы, конфликты пунктуации и все варианты для демонстрации.
4. Запусти настоящий импорт и повтори его: новые записи должны быть равны нулю.
5. Не выдавай состояние `confirmed` за независимую экспертную экспертизу, если были только голоса.

## Пользовательская демонстрация

1. `/start`: никнейм, роль, код класса, языковая пара.
2. `/pair`: доступны только языковые пары с загруженными заданиями.
3. `/task`: кнопки «Верно», «Исправить», «Пропустить».
3. После «Пропустить» новая фраза при наличии альтернативы; старая кнопка должна исчезнуть.
4. Три ученика отвечают на одну языковую пару: появление статуса `confirmed`.
5. `/me`: очки, цель дня, серия, бейджи.
6. `/top`: периоды и место класса.
7. `/report`: преподаватель видит отчёт; ученический код не открывает его.
8. Эксперт видит очередь спорных фрагментов и подтверждает решение.
9. Сайт показывает подтверждённый перевод, рейтинг, экспорт CSV/JSON.
10. REST API отдаёт строку с источником; закрытые таблицы не доступны публичному ключу.

**Не проверено автоматически:** качество языка, законность конкретных материалов,
реальные задержки Supabase и доставка Telegram-сообщений.


## Для версии с локальной библиотекой

- [ ] Если база существующая, применены `20261113_stage6_expedition.sql` и `20261113_stage7_runtime_fixes.sql` **после** stage5. Для новой базы использованы schema/seed/logic.
- [ ] Локальная база отвечает на `127.0.0.1:54321`, а не открыта на внешнем IP.
- [ ] `check_rls.py` подтверждает права `adventure_progress` и закрытость персональных таблиц.
- [ ] Один новый подтверждённый перевод БГПУ изменяет счётчик после «Обновить прогресс».
- [ ] Веб-XP не увеличивает этот счётчик, `license='demo'` также не увеличивает его.
- [ ] Ни один ключ `service_role`/`sb_secret` не вставлен в HTML и не показан в трансляции.
