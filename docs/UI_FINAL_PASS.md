## Выполненные проверки

- **PASS:** 106 unit-тестов, compileall, контракт, Ruff check и format.
- **PASS:** Playwright на 360×800, 390×844, 768×1024, 1024×768, 1440×900, 1920×1080. CDN заблокированы; системная тема dark, reduced motion; реальные пять заданий, ошибочный ответ, выход, возврат фокуса, длинные строки, отсутствие горизонтального переполнения и ошибок JS.
- **PASS:** reflow с половиной ширины настольного окна (эквивалент области страницы при масштабе 200%, минимум 320 CSS px). Это проверка reflow, а не ручное переключение масштаба браузера.
- **SKIP локально:** PostgreSQL integration — не задан `PG_TEST_ADMIN_DSN`. Docker Desktop — `/info` возвращает HTTP 500. Эти результаты не считаются успешными интеграционными проверками; полный стек проверяется отдельным заданием Actions.

Снимки после: `test-results/visual/` — главная, карта, профиль, рейтинг, переводы, эксперт, урок, завершение и reflow для каждого размера. В CI они публикуются артефактом `interface-screenshots`. До правок сохранены главная и урок на 390/1440 px во внешней рабочей папке `work/visual-before/`. Лично просмотрены главная и урок на ПК/телефоне, рейтинг, эксперт, завершение и планшетная компоновка. Остальные снимки доступны для дополнительного просмотра; пиксельный эталон не фиксируется из-за случайного выбора настоящих фраз.

## Запуск

Из корня проекта:

```powershell
python -m playwright install chromium
python tests/browser_visual_checks.py
```

Для приложения с API основной запуск прежний: `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_local.ps1`.

## TTS

Не реализована в этой итерации: при ограниченном бюджете приоритет отдан завершённому интерфейсу. Нет скачанной модели, сгенерированного аудиопакета, manifest и проверки носителем. Кнопки с имитацией башкирской речи не добавлялись. Полноценная Silero TTS требует отдельного прохода по условиям технического задания.
