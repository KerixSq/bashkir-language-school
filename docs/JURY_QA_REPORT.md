# Проверки аниме-сборки для защиты

## Исправлено

- Визуальный стиль всех пяти локальных иллюстраций унифицирован, загруженные в корпус текстовые данные не изменены.
- «Верно» и «Исправить» на главном экране вызывают те же реальные действия браузерного клиента; до входа они не создают фиктивные ответы.
- Демо-рейтинг школ, классов и учеников отмечен как **ДЕМО** и заменяется серверными данными при успешном подключении.
- На первом экране добавлен экспорт JSON/CSV из реального `translations_export`, без подмены синтетическими примерами.
- Очередь спорных переводов открывается через существующую вкладку и требует отдельного кода эксперта; никакого автоматического решения «от имени УФИЦ РАН» нет.
- На быстром ответе после уже обработанного задания больше нет повторной отправки в базу.
- Прогресс ежедневной цели в браузере использует реальное значение `daily_goal`, а не захардкоженную пятёрку.

## Не проверено

- Выполнение PostgreSQL SQL-функций и миграций на настоящем Supabase;
- Живая анонимная авторизация Supabase Auth и права RLS;
- Telegram long polling с реальным токеном;
- Подлинная запись нескольких голосов в одну языковую пару и передача на экспертную проверку;
- Работа внешних CDN в закрытой школьной сети.

## Формат экспорта

Существующая `public.translations_export` содержит **ровно** семь полей:

`fragment_id`, `text_ba`, `lang_pair`, `translation`, `source`, `confirmed`, `status`.

Экспорт JSON — массив объектов с этими ключами. CSV — те же поля в фиксированном порядке. Значения с начальными символами формул Excel безопасно префиксируются при сохранении в CSV. Схема БД для этой визуальной доработки **не изменялась**; новые миграции не требуются.

## Ручной сценарий перед демонстрацией

1. Примени уже предусмотренные миграции до stage8 включительно к своему локальному PostgreSQL.
2. Настрой в сайте публичный URL и publishable/anon-ключ. Никогда не вставляй service_role/secret в HTML.
3. Проверь анонимный вход, создание профиля и получение фразы.
4. Подожди минимальное время ответа, нажми «Верно», проверь обновление очков.
5. На второй фразе нажми «Исправить», введи текст, отправь и проверь статистику.
6. Создай несколько тестовых учеников и классов; убедись, что маркировка «ДЕМО» пропала после загрузки живого рейтинга.
7. Скачай JSON и CSV, проверь семь полей и атрибуцию источника.
8. Введи экспертный код, открой спорные записи и проверь, что код ученика не даёт доступа.
9. Выполни `scripts/smoke_test.py` и `scripts/check_rls.py` с рабочим подключением.
10. Открой страницу на телефоне и повтори первый вход.
