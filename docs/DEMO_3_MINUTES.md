# Демо на 3 минуты: не показывай фиктивные числа

Подготовка: Docker Compose запущен; выполнены миграции до stage11 (для чистого volume SQL создаётся автоматически); корпус БГПУ загружен; реальные ответы уже есть или подготовлены **три независимых профиля браузера**. Сначала выполни `smoke_test.py` и `check_rls.py` и убедись, что ошибок нет. Учебные демо-данные не называй результатами носителей.

| Время | Что показываем | Что говорим |
|---|---|---|
| 0:00–0:25 | Карта и Акбузат | «Задания превращаем в путешествие. У ученика 5 упражнений и личный прогресс». |
| 0:25–0:50 | Урок на реальных фразах БГПУ | «Источник — открытый корпус; соответствия не прошли построчную экспертизу». |
| 0:50–1:35 | Браузерные задания у трёх участников | «Ученики проверяют один перевод. На стороне SQL ответы согласуются». |
| 1:35–2:05 | SQL `translations_export`, одна подтверждённая строка | «Результат сохранён с источником, языковой парой и числом голосов». |
| 2:05–2:35 | Кнопка «Обновить прогресс» в библиотеке | «Подтверждённый перевод добавляет страницу общей библиотеки. Личные XP на это не влияют». |
| 2:35–3:00 | Публичный REST API и рейтинг | «Данные доступны для внешних образовательных систем». |

**Как сделать переход предсказуемым:** при пустой базе три участника сначала получают один фрагмент благодаря приоритету уже начатых голосований. Если в базе много накопленных ответов, заранее проверь выбранный фрагмент и не обещай автоматическое совпадение случайной выдачи. Если на публичном счётчике уже больше 15 подтверждений, покажи изменение числа, а не повторную «разблокировку» всех глав.

**Честные ограничения:** серверные голоса доступны на сайте; отдельный тренажёр хранит XP локально; словарь синонимов — ручные правила; экспертная очередь не заменяет проверку носителями; локальный Supabase нельзя публиковать напрямую.

## Проверка перед выходом к жюри

- `python tests/docker_integration.py` выполняет полный цикл на отдельном Compose-проекте с реальным БГПУ, а затем smoke/RLS, CSV и отчёт преподавателя, aiogram FSM. Транспорт Telegram в FSM-тесте заменён техническим адаптером; живой polling проверяйте отдельно со своим ботом. Том обычного приложения не используется.
- На телефоне кнопка «Начать урок» запускает пять заданий; после результата есть возврат к карте. Регистрация профиля нужна для серверной проверки, а не для тренировочных XP.
- TTS включена для 40 фраз. Нажимайте «Слушать» только там, где запись доступна; сведения об источнике и синтетическом голосе раскрываются отдельно. Не обещайте озвучку всей колоды и проверку произношения носителем.
