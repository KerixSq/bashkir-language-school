# Изменения в хакатонной сборке

Эта версия основана на компактной сборке проекта и сохраняет весь её стек.

## Исправлено

- `sql/migrations/20261113_stage5_quality.sql` — идемпотентное преобразование старых ID строк разговорников и новый безопасный выбор заданий. **Для уже развёрнутой базы применяется только эта новая миграция.**
- `scripts/import_phrasebooks.py` — ID уникальны в рамках файла, а не всего корпуса; поддерживаются целочисленные ID. `--dry-run` работает без Supabase, `--review-out` сохраняет CSV для проверки переводов и подставных ошибок; подозрительные совпадения с разной пунктуацией подсчитываются.
- `sql/logic.sql`, `bot/handlers/tasks.py` — незавершённые переводы с голосами имеют приоритет; пропуск записывается атомарно; кнопки уже завершённого задания перестают быть активными.
- `bot/handlers/registration.py`, `bot/db.py` — в регистрации предлагаются только языковые пары с заданиями, `/pair` разрешает безопасно сменить пару.
- `scripts/demo_readiness.py` — read-only сводка готовности к защите. В ней учитываются реальные Telegram-ученики и подтверждённые переводы корпуса, а не искусственные демо-данные.
- `PITCH_NOTES.md` — сценарий защиты не предлагает показывать данные после `smoke_test.py`, потому что этот тест удаляет свои временные записи.
- `.github/workflows/ci.yml` — обязательные тесты и критические ошибки Ruff; полный линтинг и форматирование выводятся как отчётные проверки.

## Сохранено

11 основных таблиц, существующие пользователи и ответы, RLS, приватные никнеймы, вес голосов, начисление очков, экспертная очередь, отчёты преподавателей, внешнее API и одна статичная веб-страница.

## Нельзя считать проверенным без реального Supabase

Выполнение stage5 на PostgreSQL, права публичного ключа, транзакционная конкуренция, доставка сообщений Telegram, результаты импорта настоящих JSONL и качество языковых соответствий. Перед показом пройди `docs/RELEASE_CHECKLIST.md`.

## Финальная локальная сборка (2026-11-13)

- Публичное SQL-представление `adventure_progress` и идемпотентная миграция `20261113_stage6_expedition.sql`.
- Кооперативные главы библиотеки (1, 5 и 15 **подтверждённых** переводов) на сайте, без фальшивых процентов, демо-источников и персональных данных.
- Локальный Supabase API `http://127.0.0.1:54321` разрешён в настройках веб-страницы; произвольный HTTP по-прежнему запрещён.
- Запуск Docker Desktop и CLI через `scripts/setup_local.ps1`, подробные шаги `docs/LOCAL_WINDOWS.md`.
- Инструкции `AGENTS.md` для Codex, сценарий `docs/DEMO_3_MINUTES.md`, тесты контракта экспедиции.
- SQL на живом локальном PostgreSQL и интеграция Telegram требуют проверки на ноутбуке — локальная проверка JavaScript не заменяет их.
