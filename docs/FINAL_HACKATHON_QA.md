# Финальный рубеж P0 хакатонной доработки

## Дополнение P1: оригинальное аудио (stage13)

Реализован импорт PCM WAV/MP3 и CSV/JSON таймкодов с явными названием и лицензией; без STT и генерации языковых данных. БД записывается атомарно, повтор не дублирует материал и не сбрасывает ответы. На сайте есть отдельное воспроизведение оригинального диапазона с обработкой отсутствующего файла. Публичные права и семь полей экспорта сохранены. Локально PASS: 143 unit, compileall, Ruff, контракт, 11 PostgreSQL integration, настоящие WAV/MP3 в Chromium/WebKit и прежние P0/экспертные/TTS-регрессии. Изолированный Docker-сценарий добавлен в Actions; локальный Docker SKIP. [Команды и ограничения](ORIGINAL_AUDIO.md).

Оригинал тестов — явно технический тон, не подлинная башкирская запись. Напоминания и P2 пока не реализованы. Ниже сохранена история предыдущих рубежей; сведения «аудио не реализовано» относятся к состоянию до stage13.

## Что выполнено

- Исправлены I001 и форматирование из 675661a. SOCKS сохранён. Tor изолирован профилем bot, фиксированное имя контейнера удалено. Отсутствующий токен и Tor больше не участвуют в старте сайта. Бот не блокируется внешним healthcheck Tor и не переходит сам на direct. Healthcheck ограничен по времени и допускает пробелы в JSON; реальная доступность Tor в сети отдельно не подтверждена.
- Главное меню, быстрый следующий шаг после ответа/пропуска/отмены; команды сохранены. Callback-меню использует именно from_user человека, а не автора сообщения-бота.
- Самостоятельный ученик без фиктивного класса: регистрация, задания, серверные очки, рейтинг. `/join` сохраняет UUID, ответы и очки. Преподаватель без класса по-прежнему не получает задания/отчёт. Изменение SQL — отдельная повторяемая stage11; формулы баллов не менялись.
- BOT_USERNAME передаётся как публичное поле конфигурации сайта; токен не передаётся. PUBLIC_WEB_URL даёт кнопки сайта, игры и библиотеки только для публичного HTTPS. При отсутствии адреса показано ограничение локального ноутбука. Публичные ссылки не означают общей учётной записи.
- Личный вклад: количество проверок/исправлений, задания сегодня, баллы, уровень, достижения, подтверждённые/ожидающие/экспертные статусы и общий прогресс пары. Точные серверные count не ограничены первой тысячей ответов; история показывает последние 20. Данные берутся только по sender текущего пользователя. Community confirmation не объявляется официальной экспертизой.
- Реальный смешанный регрессионный сценарий добавлен в Docker: aiogram-ответ → два независимых анонимных веб-пользователя → консенсус=3 → REST-экспорт → счётчик библиотеки=2 с учётом ранее проверенного перевода. Telegram-транспорт подменён, Auth/REST/PostgreSQL и браузерные ответы настоящие.

## Оставшийся объём

Зафиксирован законченный приоритетный рубеж P0 (этапы 0–3). P1/P2 в этом проходе не внедрялись, чтобы сохранить проверяемый результат в пределах ресурса выполнения:

- Пункт 4.4: сохранены synonym_map, canonical_translation, pg_trgm и защищённое экспертное решение. Нового интерфейса сравнения конкретных вариантов и их similarity ещё нет. Автоматическое понимание смысла не заявляется.
- Пункт 4.2: сохранены источники audio и таймкоды, TTS не заменяет оригинал. CLI импорта WAV/MP3 с готовой разметкой и воспроизведение оригинального диапазона ещё не реализованы. Подлинный лицензированный аудиокорпус не заявляется.
- Ежедневные уведомления: планировщик и `/remind` не реализованы; напоминания не отправляются.
- Связка учётных записей: не реализована. Профили независимы, общая база переводов и рейтинги реальны. Безопасная будущая реализация требует хешированного одноразового кода с TTL, проверки обоих владельцев, отказа при конфликтующих голосах/классах и транзакционных тестов; простое суммирование баллов недопустимо.
- Носитель не проверял переводы или произношение. Вклад сообщества не равен официальной экспертизе.

## Запуск на защите

Точные команды Windows, миграция stage11, Tor/direct и публичные параметры: [TELEGRAM_NAVIGATION.md](TELEGRAM_NAVIGATION.md). Базовый запуск сайта:

```powershell
docker compose --env-file .env.docker up -d --build --wait
```

Бот с настроенным токеном через Tor:

```powershell
docker compose --env-file .env.docker --profile bot up -d --build tor bot
```

Бот с явным прямым подключением после запуска сайта:

```powershell
$env:BOT_PROXY_URL = 'direct'
docker compose --env-file .env.docker --profile bot up -d --build --no-deps bot
Remove-Item Env:BOT_PROXY_URL
```
