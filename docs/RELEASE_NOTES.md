# Изменения платформы

## Текущая версия

- Веб-обучение с картой Акбузата, короткими уроками, локальным прогрессом и достижениями.
- Серверная проверка переводов в браузере и Telegram, коллективное согласование и защищённое решение эксперта.
- Самостоятельная регистрация без класса, вступление через /join, меню и личный вклад.
- Рейтинги по периодам, преподавательские отчёты, JSON/CSV и REST API.
- Подсказки текстового сходства, импорт WAV/MP3 с готовыми таймкодами и воспроизведение диапазонов.
- Синтезированная башкирская озвучка для 40 фраз, добровольные ежедневные напоминания.
- Устойчивая навигация, синхронизация мобильного меню, контекст раздела без вымышленных данных.
- Единые инструкции установки, безопасного обновления и резервного копирования.

Формулы очков, SQL-консенсус и семь полей REST-экспорта сохранены. Для существующей базы требуется выбранный суффикс миграций после подтверждения её версии и backup; чистая установка содержит текущую схему. Тег стабильной версии не опубликован.

Результаты проверок и ограничения — [QA](QA.md). Переводы и синтезированное произношение требуют оценки носителем; веб- и Telegram-профили не объединяются. Напоминания резервируют одну попытку в сутки, без гарантии доставки при сетевом сбое.
