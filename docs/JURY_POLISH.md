# Первый экран для защиты — башкирская аниме-игра

Основной экран сайта (`web/index.html`) показывает три обязательные для жюри вещи:

1. **Ежедневная проверка перевода.** После входа в браузере фраза и предложенный перевод приходят через `web_next_fragment`; кнопки «Верно» и «Исправить» используют тот же `web_submit_answer`, что и основной экран задания. До входа никакой вымышленной фразы не показываем.
2. **Лидерборд.** До подключения к базе отображаются три вымышленных примера с маркировкой **ДЕМО**. После получения данных из `leaderboard_users`, `leaderboard_classes`, `leaderboard_schools` отображаются реальные публичные результаты. Никнеймы, а не имена из Telegram.
3. **Экспорт и спорные случаи.** JSON/CSV загружаются из `translations_export` (ровно семь колонок: `fragment_id`, `text_ba`, `lang_pair`, `translation`, `source`, `confirmed`, `status`). Экспертная очередь открывается только с секретным кодом и использует `expert_list_queue`. Официальная проверка УФИЦ РАН пока не интегрирована.

## Иллюстрации

- `web/assets/akbuzat.webp` — оригинальная аниме-иллюстрация Акбузата для этой сборки.
- `web/assets/adventure-world.webp` — новый стилизованный пейзаж Уральских гор, с дорогой к приключениям.
- `web/assets/humay.svg`, `ural-batyr.svg`, `ural-map.svg` — новые векторные иллюстрации в той же палитре.
- Это современная художественная стилизация мифологических образов, а не научная реконструкция.
- Изображения из изданий БГПУ не используются. Лицензия корпуса в `data/phrasebooks/NOTICE` касается текстов, а не книжных иллюстраций.

## Как проверить руками

На Windows 11 в корне репозитория:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Открой `http://127.0.0.1:8000/web/`.

- Пока API не подключён, рейтинг показывает вымышленные демо-примеры и явную маркировку.
- Вкладки «Школы», «Классы», «Ученики» переключают данные.
- «Верно» и «Исправить» без задания ведут к началу урока — голос не отправляется.
- JSON/CSV без подключения честно сообщают об ошибке; фиктивный экспорт не создаётся.
- Открой «Спорные случаи для УФИЦ РАН»: появится форма с отдельным кодом эксперта.
- После подключения реального публичного API и регистрации пройди два задания, проверь серверные очки и скачай JSON/CSV.
- Проверь сайт при ширине экрана 390 px.

**Важно:** локальные unit-тесты и имитация API в браузере не заменяют проверку миграций, RLS и RPC на реальной PostgreSQL.
