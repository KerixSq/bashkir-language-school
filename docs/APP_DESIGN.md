# Интерфейс ученика — версия «Тропа слов»

В дизайне использованы распространённые паттерны языковых тренажёров: фиксированное меню, вертикальная тропа уроков, прогресс дня, крупные кнопки выбора ответа и отдельный экран занятия. Это **собственная реализация**, без логотипа, персонажей, текстов или графических файлов Duolingo. Наш герой — Акбузат, а оформление связано с башкирскими эпосами.

## Что реально работает

- Слева на компьютере и внизу на телефоне: переходы к урокам, рейтингу, базе переводов и наградам. Меню преподавателя остаётся в полной версии.
- Шесть кнопок на тропе открывают один из трёх существующих учебных этапов. Повторные кнопки — дополнительные входы в практику того же этапа, а не вымышленные новые курсы.
- Закрытые этапы становятся доступны по числу изученных фраз (8 и 20).
- Пять заданий показываются на полноэкранном экране. Выбор, исправление, продолжение, пропуск, завершение и выход имеют реальные обработчики.
- XP и серии в боковой панели отражают **только прогресс этого браузера**; классный рейтинг и коллективная библиотека получают данные отдельно из PostgreSQL.
- Если API недоступен, общий прогресс не подменяется придуманными цифрами.

## Как посмотреть

Из корня проекта запустить `python -m http.server 8000`, затем открыть `http://127.0.0.1:8000/web/`.

Колода `web/assets/learning-deck.json` включена в проект. Переводы из разговорников необходимо выборочно проверять с носителем: совпадение с корпусом не всегда означает единственную допустимую формулировку.

На Windows 11 для API и Telegram следовать `START_HERE.md`.

## Проверки

`python -m unittest discover -s tests -v` и `node` синтаксическая проверка скриптов. В браузере проверить мобильную навигацию, пять заданий, закрытые этапы, локальные XP и ошибку подключения к API. Локальный интерфейс не заменяет проверку настоящего PostgreSQL.
