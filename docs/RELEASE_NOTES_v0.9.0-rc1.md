# v0.9.0-rc1 — проект release notes

Кандидат для локальной защиты на Windows 11, не стабильный v1.0.0. Ветка release-candidate, база 0838c1a. Тег не создавался и не публиковался; предложенное имя после завершения CI — v0.9.0-rc1.

- Исправлен подтверждённый дефект: неизвестная Telegram-команда в awaiting_correction больше не сохраняется как перевод и не меняет очки/FSM. Добавлена регрессия на реальных обработчиках и PostgreSQL с подменённым Telegram transport.
- Onboarding сайта соответствует самостоятельной регистрации: код класса необязателен, вступление позже через /join.
- Единые команды Windows: чистая установка, backup вне Git, обе stage11, обновление до stage14, Tor/direct, остановка с сохранением данных.
- Подготовлены трёхминутный и резервный сценарии, матрица требований и фактические PASS/SKIP.

Сохранены P0/P1: веб-игра/Акбузат, реальные тексты БГПУ, Telegram, экспертные подсказки, исходное аудио, TTS и opt-in напоминания. Новые SQL-миграции, сервисы и зависимости в RC1 не добавлены. Существующая база требует ранее выпущенных миграций по FINAL_WINDOWS_SETUP; чистая установка уже включает их.

Ограничения: реальный Telegram/физические устройства требуют ручной проверки; TTS и перевод не проверены носителями; настоящего лицензированного исходного аудиокорпуса не добавлено; семантического объединения ответов и связывания аккаунтов нет. Напоминание резервирует одну попытку в день, не гарантирует доставку.

Проверки, SHA и свидетельства: [FINAL_RELEASE_QA.md](FINAL_RELEASE_QA.md). Готовность — READY WITH LIMITATIONS при полностью успешном RC workflow.
